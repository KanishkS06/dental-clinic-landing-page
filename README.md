# Dental Clinic Landing Page

A responsive frontend landing page for a dental clinic featuring a modern UI, smooth animations, and mobile-friendly navigation.

## Features

- Responsive navigation bar
- Mobile hamburger menu
- Animated hero section
- Modern glassmorphism stat cards
- Responsive design for all screen sizes
- Smooth hover effects and transitions

## Technologies Used

- HTML5
- CSS3
- JavaScript
